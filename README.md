# 통통 테니스! 🎾

카메라 화면을 가운데 네트로 반 나눠 **왼쪽 반에 한 명 · 오른쪽 반에 한 명**만 인식하고, 손을 라켓처럼 휘두르는 2인용 가족 테니스 게임.
설치 없이 **크롬(웹/모바일 웹)** 에서 돌아가고, 폰을 **TV에 미러링**해서 큰 화면으로 즐기는 걸 기본으로 만들었습니다.

- 빌드 도구 없음: 정적 파일 그대로 배포 (HTML + JS 모듈)
- 사람 인식: MediaPipe 자세 인식 (기기 안에서 처리, 영상 전송 없음) — 엔진·모델을 이 폴더에 같이 넣어 외부 서버 호출 없음
- 한쪽만 사람, 한쪽은 🤖 컴퓨터로 하면 혼자서도 가능. 양쪽 다 컴퓨터면 카메라 없이 구경

---

## 1. 배포 (Vercel, 약 5분)

카메라는 **https 주소에서만** 켜지므로 배포가 필요합니다.

1. 이 폴더를 GitHub 저장소에 올립니다.
2. [vercel.com](https://vercel.com) → **Add New → Project** → 저장소 선택 → Framework: **Other** → Deploy
   - Build Command·Output 설정 필요 없음 (정적 사이트)
3. 받은 `https://xxx.vercel.app` 주소를 갤럭시 크롬으로 열면 끝.
4. 크롬 메뉴 → **홈 화면에 추가** 하면 주소창 없는 전체화면 가로 앱처럼 실행됩니다.

> Netlify·Cloudflare Pages도 됩니다 (`_headers` 파일이 보안 헤더를 적용).

**PC에서 먼저 확인:** 폴더에서 `npx serve .` → `http://localhost:3000` (localhost는 https 아니어도 카메라 허용).

## 2. TV로 하기

| 방법 | 설명 |
|---|---|
| **유선 미러링** (추천) | USB-C → HDMI 어댑터로 연결. 지연이 거의 없음 |
| **무선 미러링** (스마트뷰) | 화면이 살짝 늦게 보이지만 판정은 폰에서 실시간이라 정확함. **스마트뷰 → 화면 비율 변경 → '연결된 기기에서 전체 화면'** 을 꼭 선택 (특히 폴드) |

- 폰을 **가로**로 세워 두 사람 쪽을 보게 두고, 두 사람이 **나란히 2~3걸음 뒤**에 서기. 몸 전체가 나오면 가장 좋음
- 화면 가운데 점선이 경계. **각자 자기 반쪽 안에** 서야 해요 (넘어가면 인식이 헷갈림)
- 시작 화면에서 **📷 후면 / 🤳 전면** 카메라를 고르고, 대기실의 **카메라 바꾸기**를 누를 때마다 다음 렌즈(광각 등)로 바뀝니다 (선택은 저장됨)
- 게임 화면은 항상 **16:9** 로 그려서 TV에 꽉 찹니다
- 대기실에서 각자 자기 앞에 뜬 공을 손으로 톡 → 둘 다 준비되면 3·2·1. 끝나면 다시 공을 톡 하면 한 판 더 (폰 안 만지고 계속 가능)

## 3. 게임 규칙

| 항목 | 내용 |
|---|---|
| 라켓 | 양손 끝에 라켓이 생김. 크기는 사람 크기(어깨 폭)에 맞춤 → 멀리 서도 가까이 서도 비슷하게 맞음 |
| 치기 | 방향은 **자동 도움**: 공이 상대 바로 앞, 허리~가슴 높이로 튀어 오르게 궤적을 계산. 공이 오는 높이에 손만 내밀면 됨. 세게 휘두를수록 빠른 공(받는 사람이 어른이면 조금 여기저기로), 아주 세게 치면 **스매시!** |
| 선수 종류 | 🧑 **어른**: 내 코트에서 1번 튕김(테니스 규칙) · 🧒 **어린이**: 2번까지 튕겨도 OK, 라켓 1.4배, 느리고 정확한 공을 받음 · 🤖 **컴퓨터**: 가끔 실수함 |
| 점수 | 허용 횟수보다 더 튕기거나 · 네트에 걸리거나 · 밖으로 나가거나 · 자기 쪽에 떨어지면 상대 점수 |
| 승리 | **3 / 5 / 7점** 중 고른 점수를 먼저 내면 승리 |
| 서브 | 매 점수마다 번갈아. 선수 앞에 둥둥 떠 있는 공을 라켓으로 치면 됨. 9초 동안 못 치면 자동으로 톡 넘겨 줌 |
| 랠리 | 5번마다 관중 환호 + "랠리 N!" 표시. 결과 화면에 최고 랠리·스매시 횟수 |
| 배려 | 한 사람이라도 2초간 안 보이면 자동 멈춤 → 다시 서면 이어서 |

숫자(속도·라켓 크기·튕김 횟수·승리 점수·서브 대기 시간 등)는 `js/config.js` 에서 바꿀 수 있어요.

## 4. 사람 인식 방식

- 카메라 프레임을 좌우 반쪽으로 잘라 **자세 인식(Pose Landmarker)을 두 개** 따로 돌림 → 한쪽에 두 명이 있어도 선수는 그 반쪽에서 한 명만. 반쪽씩 보니 사람이 더 크게 보여 손 위치도 더 정확
- 인식은 별도 처리(Web Worker)에서 돌려 게임 화면은 부드럽게. 그래픽 가속(GPU)이 10초간 응답이 없으면 자동으로 CPU로 전환
- 손 떨림은 필터로 줄이고 빠른 스윙은 바로 따라가게. 손이 순간 튀는 인식 오류(사람 손으로 불가능한 속도)는 판정에서 제외
- 손이 화면 밖으로 나가면 그 손의 라켓은 사라짐

## 5. 설정 화면

거울 모드(좌우 반전), 효과음/배경음악, 인식 화질(최고/고화질/표준/절전), 성능 정보 표시.
- **성능 정보 표시**를 켜면 화면 아래에 화면 fps·인식 fps·인식 시간·GPU/CPU가 나와요.
- 손 인식이 둔하면 **최고**(정확한 모델), 화면이 끊기거나 폰이 뜨거우면 **표준/절전**으로.
- PC 확인용 주소 옵션: `?debug`(성능 정보) · `?mouse`(왼쪽 선수를 마우스로) · `?cpu`(그래픽 가속 끄기)

## 6. 보안·개인정보

| 위험 | 대응 |
|---|---|
| 카메라 영상 유출 | 영상은 폰 메모리 안에서만 처리. 저장·전송 코드 없음. 게임 밖 화면에선 카메라를 바로 끔 |
| 외부 스크립트 변조·추적 | 엔진·모델·코드 전부 자체 호스팅. CSP로 외부 스크립트·외부 통신 모두 차단 (MediaPipe 내장 사용통계 전송도 차단됨) |
| 개인정보 수집 | 서버 없음. 선수 이름·설정은 이 기기(localStorage)에만 저장 |
| XSS | 이름은 캔버스·textContent 로만 출력, 꺾쇠·제어문자 제거, 6글자 제한 |
| 클릭재킹·기타 | frame-ancestors none, X-Frame-Options, nosniff, no-referrer, HSTS, 카메라 외 권한 차단 |

## 7. 파일 구조

```
index.html              화면 구성
manifest.webmanifest    홈 화면에 추가용
css/style.css           디자인
js/config.js            ★ 코트·규칙·선수 종류·인식 화질 숫자
js/main.js              화면 흐름 (시작·대기실·결과·설정)
js/game.js              게임 엔진 (공 물리·라켓 판정·점수·컴퓨터 선수·그리기)
js/duo-vision.js        카메라 + 좌우 반쪽 인식 연결
js/pose-core.js         좌우 반쪽 자세 인식 핵심 (워커/화면 공용)
js/pose-worker.js       별도 처리(Web Worker)
js/sound.js audio.js    효과음·배경음 (직접 합성, 음원 파일 없음)
js/fullscreen.js        전체화면 (OS·브라우저별 처리)
js/util.js              공용 유틸
vendor/, models/        사람 인식 엔진·모델 (수정 불필요)
vercel.json, _headers   보안 헤더
```

## 8. 알아두면 좋은 점

- 실내가 너무 어둡거나 사람 뒤가 복잡하면 인식이 거칠어집니다. 밝은 곳, 단순한 벽 앞이 좋아요.
- 구경하는 가족은 카메라에 안 나오게(또는 선수보다 뒤에) 서 주세요. 반쪽에 여러 명이 있으면 먼저 잡힌 한 명이 선수가 돼요.
- 처음 실행할 때 인식 엔진을 받느라 몇 초 걸리고, 이후엔 캐시됩니다.
- 라이선스: MediaPipe 엔진·모델은 Apache-2.0 (`vendor/mediapipe/NOTICE.txt`, `models/NOTICE.txt`).
